# CMGS-Tutorials
Some tutorials for the **"Concrete Music Gran Studio"**, or **CMGS**, available from the https://github.com/jack461/CMGS directory. 

The **Tuto-01** is a large project using the **CMGS**, which itself needs the REAPER DAW (v7.25 or later), available from http://reaper.fm/download.php.

To download this tutorial, click on the green "Code" button, and select "Download ZIP". Unzip it, and follow the explanations of "Tuto-01/README.md" to install it.
